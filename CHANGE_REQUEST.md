# Proposed change: Create work items from the queue

## Summary

Add a dialog that lets a team member create a work item directly from the work queue.

## Expected behavior

- A work item has a required title and a selected project.
- New work is assigned to the current user, starts open, and uses medium priority.
- A successfully created item appears immediately at the top of the queue and updates the summary counts.
- Canceling or closing the dialog does not create an item.
